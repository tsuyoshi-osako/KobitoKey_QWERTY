# roBa準拠 5レイヤー化の変更内容（feature/roba-5layer）

配置図：[keymap_5layer.png](keymap_5layer.png)

## 1. レイヤー構成

| 番号 | 名称 | 有効になる操作 |
|---|---|---|
| L0 | DEFAULT | 通常 |
| L1 | NUM_ARROW | Enter/L1（36）を長押し |
| L2 | FUNCTION | Space/L2（33）を長押し |
| L3 | MOUSE | 右トラックボールを動かすと自動で有効（番号は変更なし） |
| L4 | BLUETOOTH | 右下 `/L4（39）を長押し（新設） |

## 2. 変更前後の比較（変わったキーのみ）

キーポジション番号は左上0〜右下39（各行10キー）。32〜34が左親指、35〜37が右親指。

### L0 DEFAULT

| 位置 | 変更前 | 変更後 | 理由 |
|---|---|---|---|
| 19 | ; | - | roBaと同じ位置。; はL1へ |
| 20 | Z | タップZ／長押しShift | roBa準拠 |
| 29 | ' | / | roBaと同じ位置。' はL2へ |
| 30 | 左Shift | Ctrl | 合意済み配置図どおり |
| 31 | Alt | Win | 同上 |
| 32 | Win | Alt | 同上 |
| 33 | Space/L2 | Space/L2 | 変更なし |
| 34 | Ctrl | Backspace | 同上 |
| 35 | Backspace | Tab | 同上 |
| 36 | Enter/L1 | Enter/L1 | 変更なし |
| 37 | 右Shift | Ctrl+Shift+C | エクスプローラーでフルパスをコピー |
| 38 | 右Shift | 右Shift | 変更なし |
| 39 | タップ/／長押しAlt | タップ`（Shiftで~）／長押しL4 | L4の入口 |

### L1 NUM_ARROW（旧NUMBER）

roBaのL1を基準に全面変更。

| 変更前 | 変更後 |
|---|---|
| 左手に数字0〜9、右手に矢印 | 左手E・S・D・Fに矢印（↑←↓→）、右手に数字（roBaと同じテンキー配列） |
| なし | A＝Ctrl+Space（IME切替）、G＝Ctrl+C、B＝Ctrl+V |
| - = + * / [ ] | + ; / * は右手に。- はL0、= [ ] はL2へ移動 |
| 33＝Shift | 透過（L2への切替が効く） |

数字はroBaと同じテンキーのキーコード（KP_N0〜9）です。WindowsでNumLockがオフだと数字ではなくHome等になります。

### L2 FUNCTION

| 変更前 | 変更後 |
|---|---|
| 左手にBT選択・解除・全解除 | L4へ移動。左手上段はF1〜F5 |
| 右手にF1〜F12 | 上段F1〜F10、N・M位置にF11・F12 |
| なし | 中段に ! @ # $ % ^ & * ( )（roBa準拠） |
| なし | Z位置にPrtSc、X〜B位置にHome・PgUp・PgDn・End |
| なし | 右手下段に = [ ]、37に ' |
| 35＝Delete | 変更なし |

### L3 MOUSE

| 位置 | 変更前 | 変更後 |
|---|---|---|
| 11・12・13（S・D・F） | 透過 | 左クリック・中クリック・右クリック |
| その他 | 右手クリック6・7・8、Shift・Win・Alt・右Alt、L0へ戻るキー2つ | 変更なし |

### L4 BLUETOOTH（新設）

| 位置 | 機能 |
|---|---|
| 0〜4（Q〜T） | 接続先0〜4を選択 |
| 10（A） | 選択中の接続先のペアリング解除 |
| 11（S） | 全接続先のペアリング解除 |
| 24（B）・25（N） | ブートローダー起動（左右それぞれの本体が対象） |

### 同時押し（コンボ）

2キーとも別の機能が割り当たっているレイヤーでは無効にしています。

| キー | 出力 | 変更前 | 変更後の有効レイヤー |
|---|---|---|---|
| Q+W（0,1） | Esc | 全レイヤー | L0・L1・L3 |
| A+S（10,11） | Tab | 全レイヤー | L0 |
| D+F（12,13） | 英数 | 全レイヤー | L0 |
| J+K（16,17） | かな | 全レイヤー | L0・L3・L4 |
| 右Shift+`（38,39） | Esc | なし（新設） | L0・L2 |

右Shift+` は判定を30msに短くし、直前150ms以内に別のキーを打っていた場合は発動しないようにしています。Shiftを押してから少し間を置いて ` を押すと ~ になります。

## 4. roBaから持ってこなかったもの

| roBaの機能 | 判断 |
|---|---|
| I長押しでL5 | roBaのL5は全キー透過（roBa本体のスクロール用）。小人キーは左ボールでスクロールするため、Iは通常のIに |
| L6（BT選択・ブートローダー・1〜3） | L4 BLUETOOTHに統合 |
| L3のBT・Ctrl+Tab・Win+Shift+矢印など | roBaのL3はSQT長押しで入る別レイヤー。小人キーのL3はマウス専用のため対象外 |
| 内側列のEsc・Ctrl+X・Ctrl+C・Ctrl+V | 小人キーに該当キーがないため、Esc＝コンボ、Ctrl+C/V＝L1に置き換え。Ctrl+Xは配置なし |
| ' をL0の親指（長押しL3） | L0に置き場所がないためL2の37へ |

## 5. ファームウェアの書き込み手順

1. GitHubの Actions で、このブランチのビルドを開き、Artifacts の `firmware` をダウンロードして展開する
2. 左側の本体をUSBでPCにつなぎ、リセットボタンを素早く2回押す（USBドライブとして認識される）
3. 名前に `KobitoKey_left` を含む `.uf2` をドライブにコピーする（コピー後に自動で再起動）
4. 右側の本体も同様に、名前に `KobitoKey_right` を含む `.uf2` をコピーする（`settings_reset` の `.uf2` は使わない）
5. 動作確認：文字入力、Z長押しShift、Space長押しでL2、Enter長押しでL1、右ボールでポインター・L3、左ボールでスクロール、`長押しでL4

## 6. ZMK Studioに保存した設定がある場合

左側はZMK Studioが有効です。ZMK Studioで変更して「保存」したキー配置は本体の設定領域に残り、新しいファームウェアのキーマップより優先されます。

- 書き込み後に古い配置のままのキーがあれば、ZMK Studioの「Restore Stock Settings」で、Studioで保存した変更を取り消す（Bluetoothのペアリングは消えない）
- それでも直らない場合だけ、`settings_reset` のファームウェアを左右に書き込んでから本体のファームウェアを書き直す。この方法はBluetoothのペアリング情報も消えるため、PC側の登録削除と再ペアリングが必要
- コンボはZMK Studioでは編集できません（キーマップファイルでのみ変更可）
